# Todos

Language for the todo application, as specified in issue #1.

## Language

**Todo**:
An item owned by a user, with a title and a completion state.
_Avoid_: Task, reminder

**Title**:
The nonempty text describing a todo.
_Avoid_: Name, description

**Completed**:
The state indicating that a todo is done. A newly created todo is incomplete.
_Avoid_: Finished, checked

**Owner**:
The user to whom a todo belongs; other users cannot access it.
_Avoid_: Assignee

**Provisioned account**:
An email/password account created for the owner outside the application UI.
_Avoid_: Signup, registration
